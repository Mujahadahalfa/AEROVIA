# AEROVIA - Move With Purpose.
PWA pelacak olahraga GPS. JavaScript murni, tanpa backend, data di IndexedDB.

## Deploy ke GitHub Pages
1. Buat repo baru, upload seluruh isi folder ini (index.html harus di root).
2. Settings > Pages > Source: Deploy from a branch > main / (root).
3. Buka `https://USERNAME.github.io/NAMA-REPO/` di Chrome Android, lalu menu > Pasang aplikasi.

## Uji lokal
`python3 -m http.server 8000` lalu buka http://localhost:8000 (GPS butuh HTTPS atau localhost).
